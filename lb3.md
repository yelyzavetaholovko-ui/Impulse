# Лабораторна робота №3. Модульне тестування
**Проєкт:** Impulse (Командна робота)
**Студент:** Богдан (Компонент: Трекер прогресу / ProgressTracker)

## 3.1 Мета роботи
Набуття практичних навичок із написання модульних тестів із використанням промислових фреймворків тестування (xUnit для C#). Оволодіння формальними техніками проєктування тестів: еквівалентне розбиття (Equivalence Partitioning) та аналіз граничних значень (Boundary Value Analysis). Отримання досвіду інтерпретації метрик покриття коду (code coverage) та поліпшення тестового набору до досягнення порогу покриття рядків не менше 80%.

## 3.2 Вихідний код реалізованого модуля
Файли з кодом `ProgressTracker.cs` та тестовим набором `ProgressTrackerTests.cs` успішно створені та завантажені в репозиторій у гілку `Lb-Lysun`. Логіка містить 3 нетривіальні методи (валідація з винятками, розгалуження та адаптивний цикл перерахунку термінів схуднення ШІ).
